- 🧱 **Data Modeling:** Star schema, dimensional modeling, Medallion architecture (Bronze/Silver/Gold), SCD Type 1 & 2
- 🏗️ **Data Engineering:** ELT/ETL pipelines, watermark-driven incremental loads, PySpark notebooks, dbt, data quality testing, T-SQL
- 🗃️ **Data Platforms:** Microsoft Fabric (Lakehouse, Data Pipelines, Dataflow Gen2, Direct Lake), Snowflake, Azure (ADLS Gen2, Storage Integrations), Databricks, SQL Server

### 📌 What I focus on

- Building **Data Lakehouse / Data Warehouse solutions** on modern data platforms with dedicated transformation tools, delivered as a finished analytical product
- Building **healthy, well-documented data models** — from raw/chaotic datasets to clean star schemas ready for reporting
- Full **Bronze → Silver → Gold** pipelines with automated orchestration and data quality checks
